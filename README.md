# 个人极简导航页面版本说明

1. V.0.1 第0.1版

   * 时间：2026-1-13-04:15:00
   * 第一版首页，可拖动图标。可增加、删除链接。

2. V.0.2 第0.2版

   * 时间：2026-1-13-04:45:00
   * 增加导航按钮。链接按不同功能分类。
     
3. V.1.0 Release 
   * 正式版
   * 时间：2026-1-13-05:25:00
   * 增加导出、导入按钮。可以随时备份链接数据，更换电脑时能够同步。
   * 通过导出按钮对当前导航页进行备份，备份文件名为：nav_config.json。将其保存好。
   * 恢复导航页时，点击导入按钮，选择上述备份文件，即可恢复。
